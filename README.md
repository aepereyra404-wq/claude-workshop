# Cloud Code Workshop

Welcome to the **Claude Code** Cloud Code workshop! This repository contains the starter material and guidelines for participants.

## Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-org/claude-workshop.git
   cd claude-workshop
   ```
2. **Install the recommended Claude Code plugin**
   - **[Context Mode](https://github.com/mksglu/context-mode)** – provides extra context to Claude Code and other AI agents.
   - Install it using Claude Code commands:
     ```
     /plugin marketplace add mksglu/context-mode
     /plugin install context-mode@context-mode
     ```
3. Follow the workshop instructions in the `examples/` folder (or as provided by the instructor).

## Suggested Workflow

- Open the project in VS Code with the Context Mode plugin enabled.
- Use Claude Code to generate or refactor code, but always review the suggestions.
- Write tests for any new functionality (see `CONTRIBUTING.md`).

Enjoy the workshop and happy coding!
